│  🚀 QUICK START                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    1. Install dependencies:
       $ cd dayflow-frontend
       $ npm install axios

    2. Create .env file:
       VITE_API_URL=http://localhost:5000/api

    3. Start frontend:
       $ npm run dev

    4. Start backend (separate terminal):
       $ cd ../dayflow-backend
       $ npm run dev

    5. Open browser:
       http://localhost:5173/login

    6. Login and test all features! 🎉
